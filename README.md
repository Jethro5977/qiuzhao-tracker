# 秋招投递台账

一个面向 2027 届秋招的个人投递追踪器，用来集中管理岗位、笔试面试进度和下一步日程，并在保存前提示可能的重复投递。

## 功能

- 表格与看板双视图
- 按状态、公司、岗位、地点筛选和排序
- 公司、岗位族、批次、地点、岗位链接综合去重
- 未来 14 天笔试与面试日程
- 浏览器本地自动保存
- 截图 OCR：上传投递、笔试或面试页面截图，生成待核对的岗位与进度记录
- JSON 备份和恢复
- 直达实时更新的腾讯文档岗位库

## 本地运行

```bash
npm install
npm run dev
```

## 部署

推送到 `main` 分支后，GitHub Actions 会构建静态站点并发布到 GitHub Pages。首次发布时，需要在仓库的 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。

> 数据只保存在当前浏览器中。换设备或清理浏览器数据前，请先使用“备份”导出 JSON 文件。
# 自动保存与序号录入

编辑框输入会立即保存为本机草稿，关闭或刷新后点击「继续编辑」恢复。草稿可以保留未填写完的日期和链接；点击「保存记录」通过校验后才加入台账。多窗口草稿冲突或浏览器存储失败会明确提示，不覆盖另一窗口的数据。

首页「按原表序号录入」支持 CSV / TSV 岗位源表。首次导入必须包含「序号、公司名称、招聘岗位」表头，之后输入序号即可填充表单并继续使用重复投递检查。所有额外原始列保存在备注中，岗位源表与投递台账分开存储。更新源表不改变个人投递进度。

腾讯原表目前不允许访客复制或导出，未接入自动抓取或实时同步。请使用有权限获取的源表文件；网页不会凭空生成序号对应的岗位。索引和草稿保存在当前浏览器，现有 JSON 台账备份不包含源表索引及未提交草稿，请保留原始源表文件并先保存草稿再备份。

## 截图识别

首页「截图识别并更新进度」支持 PNG、JPG、WEBP、GIF。识别在浏览器本机进行；首次识别会下载中文模型。系统会识别公司、岗位、当前状态、页面更新时间和平台提示，并先生成候选记录。请逐条核对字段、投递日期和重复提示后再保存到台账。
